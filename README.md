# BaseballLife-Ai-Support

ブラウザゲーム「Baseball Life（BBL）」を題材とした育成シミュレーションと、将来的な強化学習環境の構築を目指す個人開発プロジェクトです。

## 概要

BBLの育成ルールをPythonで再現し、疑似的な選手育成をシミュレーションできる環境の構築を進めています。

今後はシミュレータをGymnasiumに接続し、強化学習により育成方針を探索できる環境を構築します。

最終的には、ユーザがGUIから現在能力・目標能力を入力することで、次に取るべき行動を提案するシステムの構築を目指します。

## 設計

モジュール間の責務を分離し、ゲームルールを再現するシミュレーターと、評価・報酬、強化学習環境を独立させる構成を検討しています。

詳細な設計については、`doc/` 配下の設計書を参照してください。
