== はじめに
本システムは、野球選手育成ブラウザゲーム『Baseball Life（以下BBL）』において、プレイヤーの現在能力および環境の状況と、設定された目標能力に基づき、最適な行動を推奨する意思決定支援システムである。

本システムの開発にあたっては、強化学習フレームワークである「Gymnasium」を採用し、DQN（Deep Q-Network）等の強化学習アルゴリズムを用いて最適化を行う。
強化学習のモデル訓練を高速かつ効率的に行うため、BBLのゲームロジックおよび環境（ステータス遷移や確率要素など）をPython上で再現するカスタムシミュレーターを構築する。

本設計書は、このBBL再現シミュレータープログラムにおける各モジュールの仕様について定義したものである。

=== bbl_playerモジュール群
本モジュールでは、BBLにおける選手データの管理を行う。
選手能力のみならず所持アイテムや恋愛の状況、各行動の実施可否などのマスクデータも本モジュールで管理する。

==== player.py
player.pyはbbl_playerモジュール群に在籍する唯一のモジュールである。
本モジュールで選手状態および次に取り得る行動の状態をすべて管理する。メソッドは持たず、計算処理を行わない。
変数は全て``bbl_action``または``bbl_rules``の何れかから更新処理を行う。

=== bbl_envモジュール群
本モジュールではBBLの進行管理を行う。
行動回数の消費を行う``action.py``に加え、買い物など行動回数に関係ない環境の変化についてもここで行う。
事実上、ユーザが触る画面の再現を行うモジュール群である。

==== bbl_env.py
本モジュールは、BBLにおけるプレイヤーの行動管理を行う中心的なスクリプトである。
プレイヤーが選択可能なアクションを各サブモジュールに分散定義し、環境全体の進行を制御する。
言うなれば人間を再現するモジュールである。

本モジュールは変数のメンバを持たず、サブモジュールを呼び出すメソッドのみを定義する。
